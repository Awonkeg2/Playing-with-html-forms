# Awonke Gana Portfolio

A responsive portfolio website built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page content and SEO metadata
- `style.css` — responsive yellow, charcoal and off-white design
- `script.js` — mobile navigation, project filters, reveal animations and email form
- `assets/` — profile photo and portfolio project images

## Contact
The contact form is configured to open an email to `awonkeg2@gmail.com`. The phone number and WhatsApp link are also included in the contact section.

## Publish free with GitHub Pages
1. Push this project to a GitHub repository.
2. Go to repository **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait for GitHub Pages to publish the site.

The contact form uses `mailto:` and opens the visitor's email app. It does not send messages through a server.
